# URC 2027 communications requirements and implementation matrix

Source: the user-supplied 15-page **University Rover Challenge Rules 2027.pdf**, SHA-256 `356549544e86041938e0d5b633cf7d0bb3875e2777f3be0d8bc676dd0734678d`. Page numbers below count physical PDF pages from 1. The [official Q&A](https://urc.marssociety.org/home/requirements-guidelines/qa) was also read on 2026-10-13 (last listed update 2026-10-11). See [rules-source.md](rules-source.md) for verified source URLs. The current organizer-linked PDF was downloaded on the same date and exactly matches the attachment’s SHA-256 and extracted text. This matrix covers communications, C2, autonomy-control integration, and related operating constraints; it is not a complete compliance assessment of the entire rover.

**Status meanings:** **Software support** means the described behavior exists and has supporting tests, within the simulator/application boundary. **Partial** means a supporting software function exists but substantial mission capability, hardware, or operational evidence remains missing. **Manual/hardware** means software cannot establish the requirement. **Unimplemented** means the mission capability is absent. No row claims overall physical or competition compliance.

## Engineering controls that are not explicit URC requirements

These mechanisms support a more robust communications system, but the PDF does not mandate these exact protocols, algorithms, thresholds, or package formats:

| Control | Implementation | Verification scope |
| --- | --- | --- |
| Bounded authenticated application messages | `comms/protocol.py` uses HMAC-SHA256, canonical JSON, explicit schema/size/depth limits and the MRDT RoveComm codec wrapper. | Authentication protects integrity/peer knowledge of the shared key; it is not encryption or RF access control. See protocol documentation and automated tests. |
| Defensive MRDT packet integration | `comms/codec.py`, native wrapper, and preserved upstream sources under `vendor/mrdt`. | `tests/test_codec.py` covers exact wire bytes, network byte order, truncation, invalid headers, size limits, arbitrary packets and native output capacity. Compatibility of this application payload with an existing MRDT rover is not implied. |
| Bounded resumable package transfer | `comms/packages.py` uses declared lengths/chunk counts, bounded stores, canonical JSON, SHA-256, idempotent chunks, immutable package identity and separate validation/activation. | Digest checks identify corruption; message HMAC supplies shared-key authentication. Products are expressly synthetic waypoints, not drone imagery, reconstruction, traversability or autonomous flight. |
